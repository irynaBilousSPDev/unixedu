# uniXedu WordPress Theme

Custom WordPress theme built for the uniXedu website.

## Requirements

- WordPress: 6.0+
- PHP: 8.0+
- Node.js + npm (for local builds)

## Install (Theme)

1. Copy this folder to `wp-content/themes/unixedu/`
2. In WP Admin → Appearance → Themes, activate **uniXedu**

## Development (Build assets)

Install dependencies:

```bash
npm install
```

Development watch:

```bash
npm run dev
```

Production build:

```bash
npm run build
```

Outputs:

- `assets/dist/css/main.css`
- `assets/dist/js/main.js`

## Theme structure (high level)

- `assets/src/` — SCSS + JS sources
- `assets/dist/` — compiled assets (generated by Gulp)
- `blocks/` — Gutenberg blocks (auto-registered from `block.json`)
- `inc/` — theme setup/enqueue/helpers
- `static/` — permanent brand assets (not processed by Gulp)

## Gutenberg blocks

Blocks are auto-registered by scanning `blocks/*/block.json`.

Current blocks:

- `unixedu/hero`
- `unixedu/who-cards`

## Notes

- `functions.php` is loader-only (includes files from `inc/`).
- Permanent brand assets should live in `static/` (not `assets/src/images`).
